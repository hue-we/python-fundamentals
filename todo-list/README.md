# To-Do List Manager

Day 1 of week 2. First real project using lists properly instead of just
single variables. A simple to-do list you can add to, remove from, and view.

## What it does

Lets you add tasks, remove tasks by number, and view your current list.
Keeps running until you type quit.

## How to run it

```
python todo_list.py
```

Type add, remove, view, or quit and follow the prompts from there.

## Notes to self

- First time really using a list to store more than just numbers, felt

- Used enumerate to show task numbers starting at 1 instead of 0, small

- Want to come back and add a way to mark tasks done instead of only
