# Python Fundamentals

Getting back into coding after a bit of a break, and doing it properly this
time. Instead of jumping straight back into frameworks I decided to slow
down and rebuild the basics first. This repo is just my practice log while
I do that.

## Structure

Each folder is one exercise, roughly in the order I built them:

- `01-dice-roller/` dice game, functions and loops
- `02-mad-libs/` string formatting, user input
- `03-number-guesser/` conditionals and loops together
- `04-rock-paper-scissors/` comparison logic
- `05-calculator/` functions with parameters and return values

(more folders get added as I go)

## Why this exists

I'm already comfortable with C#/.NET and the MERN stack, but I wanted to
slow down and actually enjoy writing code again instead of just shipping
features. Python felt like the right place to reset. Simple syntax, fast
feedback, easy to stay in "just build something small" mode.

Once this feels solid I'm moving on to Java, a proper C# refresh, and SQL.
