# List Comprehensions

Day 5 of week 2, last one for the data structures stretch. This one is
less about a new data type and more about a cleaner way to build lists
using stuff I already know.

## What it does

Walks through a few list comprehension examples, starting with a plain
loop and then rewriting it as a comprehension, then builds on that with
filtering, transforming, and building tuples.

## How to run it

```
python list_comprehensions.py
```

No input needed, just run it and it prints out each example.

## Notes to self

- Comprehensions felt confusing at first but once I saw the loop version

  append squeezed into one line
- Filtering with an if at the end is basically the same idea as the if
